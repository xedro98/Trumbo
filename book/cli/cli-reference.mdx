## Synopsis

```bash
trumbo [options] [command] [prompt]
```

## Help Menu (Source of Truth)

```text
Usage: trumbo [options] [command] [prompt]

Trumbo CLI - AI coding assistant in your terminal

Arguments:
  prompt                       Your prompt. Default to start in act mode with auto-approve enabled.

Options:
  -V, --version                Output the version number
  -p, --plan                   Run in plan mode
  --json                       Output messages as JSON instead of styled text
  --auto-approve <boolean>     Set tool auto-approval for all tools (default: true)
  -t, --timeout <seconds>      Optional timeout in seconds (default: 0 for no timeout)
  -m, --model <model-id>       Model to use for the session with the selected provider
  -v, --verbose                Show verbose output
  -c, --cwd <path>             Working directory
  --config <path>              Configuration directory (default: ~/.trumbo/data/settings)
  --data-dir <path>            Use isolated local state at this directory path (default: ~/.trumbo)
  --thinking <level>           Set reasoning effort level between none|low|medium|high|xhigh (default: medium)
  --retries <count>            Maximum consecutive mistakes (retries) before halting
  --hooks-dir <path>           Directory path to additional hooks for runtime hook injection (default: ~/.trumbo/hooks)
  --acp                        Run in Agent Client Protocol (ACP) mode for editor integration
  -i, --tui                    Open the terminal user interface (TUI) for interactive sessions
  --id <session-id>            Resume an existing session by ID
  -k, --key <api-key>          API key override for this run
  -P, --provider <id>          Provider id (default: trumbo)
  -s, --system <system-prompt> Override the default system prompt
  -z, --zen                    Start a session that runs in the background hub
  -h, --help                   display help for command

Commands:
  auth [options] [provider]    Authenticate a provider and configure what model is used
  config [options]             Show current configuration
  connect [options] [adapter]  Connect to an editor or IDE adapter
  mcp                          Manage MCP servers
  dev                          Developer tools and utilities
  doctor                       Diagnose and fix configuration issues
  history|h [options]          List session history or manage saved sessions
  hook                         Handle a hook payload from stdin
  plugin                       Manage Trumbo Plugins
  schedule                     Manage scheduled tasks
  hub                          Manage the local hub daemon
  update [options]             Check for updates and install if available
  version                      Show Trumbo CLI version number
```

## Commands

### `trumbo` (default)

Launch the interactive TUI or run a one-shot prompt.

```bash
trumbo
trumbo "your prompt here"
trumbo "Run tests and fix failures"
echo "prompt" | trumbo
```

### `login`

Sign in with Trumbo device-code authentication (opens your browser).

```bash
trumbo login
```

### `logout`

Clear the stored Trumbo token.

```bash
trumbo logout
```

### `trumbo`

Authenticate and print subscription / plan / rate-limit status.

```bash
trumbo trumbo
trumbo trumbo status
```

### `agent`

Run the agent headlessly (no TUI): stdio, leader, or serve modes — for
scripting and CI.

```bash
trumbo agent
trumbo agent --stdio
trumbo agent --serve
```

### `models`

List the available model catalog (Quartz family).

```bash
trumbo models
```

### `mcp`

Manage MCP server configurations. See [MCP](/mcp/mcp-overview).

```bash
trumbo mcp
```

### `plugin`

Manage Trumbo plugins — install from file URLs, npm, git repositories, or
local paths. See [Plugins](/customization/plugins).

```bash
trumbo plugin install <source>
trumbo plugin i <source>
```

### `memory`

Manage cross-session memory.

```bash
trumbo memory
```

### `sessions`

List, search, and restore past sessions.

```bash
trumbo sessions
trumbo -c            # continue the most recent session
trumbo -r            # browse saved sessions
```

### `worktree`

Manage git worktrees for parallel/agent work.

```bash
trumbo worktree
```

### `doctor`

Check the terminal, clipboard, and color support.

```bash
trumbo doctor
```

### `update`

Check for updates and install via npm (`@trumbodev/cli`).

```bash
trumbo update
```

### `version` | `v`

Print the version string.

```bash
trumbo --version
trumbo version --json
```

### `completions`

Generate shell completion scripts.

```bash
trumbo completions bash
trumbo completions zsh
```

### `inspect`

Print the discovered configuration (paths, providers, settings).

```bash
trumbo inspect
```

### `leader`

List, inspect, or kill leader processes.

```bash
trumbo leader list
trumbo leader info <pid>
trumbo leader stop-all
```

### `export`

Export a session as Markdown.

```bash
trumbo export <session>
```

### `trace`

Export or upload trace data.

```bash
trumbo trace
```

### `wrap`

Run a command with clipboard forwarding.

```bash
trumbo wrap -- <command>
```

### `du` | `disk-usage`

Show disk usage by the CLI's data directory.

```bash
trumbo du
```

## Environment Variables

| Variable | Description |
|----------|-------------|
| `TRUMBO_DATA_DIR` | Custom configuration directory (replaces `~/.trumbo/data/`) |
| `TRUMBO_HUB_ADDRESS` | Override hub address (default: `127.0.0.1:25463`) |
| `TRUMBO_SESSION_BACKEND_MODE` | Force backend mode (`local`, `hub`, `remote`, `auto`) |
| `TRUMBO_SANDBOX_DATA_DIR` | Sandbox session storage directory |
| `TRUMBO_SANDBOX` | Enable sandbox mode |
| `TRUMBO_HOOKS_DIR` | Additional hooks directory |
| `TRUMBO_BUILD_ENV` | Set to `development` for debug features |
| `TRUMBO_DEBUG_PORT_BASE` | Base port for Node.js inspector |
| `TRUMBO_COMMAND_PERMISSIONS` | JSON policy restricting shell commands (see below) |

### TRUMBO_COMMAND_PERMISSIONS

Restrict which shell commands the agent can execute:

```bash
export TRUMBO_COMMAND_PERMISSIONS='{"allow": ["npm *", "git *"], "deny": ["rm -rf *", "sudo *"]}'
```

| Field | Type | Description |
|-------|------|-------------|
| `allow` | `string[]` | Glob patterns for allowed commands. If set, only matching commands are permitted. |
| `deny` | `string[]` | Glob patterns for denied commands. Deny rules always take precedence. |
| `allowRedirects` | `boolean` | Whether to allow shell redirects (`>`, `>>`, `<`). Default: `false`. |

## JSON Output Format

When using `--json`, each message is a JSON object on its own line:

```json
{"type": "say", "text": "I'll create the file now.", "ts": 1760501486669, "say": "text"}
```

| Field | Type | Description |
|-------|------|-------------|
| `type` | `"ask"` or `"say"` | Message category |
| `text` | `string` | Message content |
| `ts` | `number` | Unix timestamp in milliseconds |
| `say` | `string` | Subtype when `type` is `"say"` |
| `ask` | `string` | Subtype when `type` is `"ask"` |
| `reasoning` | `string` | Model reasoning (if available) |
| `partial` | `boolean` | `true` while streaming |

```
  data/
    settings/
      providers.json             # API keys and provider config
      rules/                     # Global rules
      skills/                    # Global skills
    teams/                       # Team state
    sessions/                    # Session database (SQLite)
    logs/
      hub-daemon.log             # Hub logs
  plugins/                       # Global plugins
    _installed/                  # Managed by `trumbo plugin install`

.trumbo/                          # Project root
  rules/                         # Project rules
  skills/                        # Project skills
  hooks/                         # Lifecycle hooks
  plugins/                       # Project plugins
  mcp.json                       # MCP server config
  agents.yaml                    # Agent definitions
```
